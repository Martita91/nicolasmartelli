Real tools for real problems, mostly built with Claude Code. Each one taught me something about putting AI to work in finance and small business.

Personal finance

Housenancials

StackReact, Vite, Tailwind, Supabase (auth + data), Vercel, Claude API RoleProduct, design and build

A household financial plan in one place: objectives, net worth, monthly budget, and a 30-years-to-retirement investing projection.

  • AI Insights: a serverless function sends the household's figures to Claude, which writes plain-English observations on savings rate, goal timelines and risks.
  • Security by design: every user's data is isolated with Supabase Row Level Security; the API key never reaches the browser.
  • Finance logic first: projections are calculated in code, and the AI only explains them.

Market analytics

Car Report

StackPython, pandas, charts, PDF generation, static HTML RoleData analysis and build

Feed it the listings for any make and model and it produces a used-car market report, in English or Spanish.

  • PDF report: summary, charts, what drives price (year, km, transmission, trim) and the five best-value listings.
  • Interactive price calculator: see where a specific car sits against the market, with comparable listings and filters. Opens with a double click, no server.
  • Client-ready: generates private, expiring share links for buyers.

Productivity · privacy

Meeting Notes

StackElectron, Windows audio capture, whisper.cpp, local LLM (Ollama) RoleBuild

Think Granola, but local. A Windows tray app that records your computer's audio and microphone, transcribes the meeting and writes a summary, decisions and action items as Markdown.

  • Private by default: no accounts, no cloud storage, no telemetry. It can run fully offline.
  • Works with any call app: Zoom, Teams or Meet, because it captures system audio.
  • One shortcut to start and stop. Notes land in a folder, ready to search.

Community · payments

Thursday F.C.

StackReact, TanStack Start, Supabase, Stripe, Vercel RoleProduct and build

A web app that runs my weekly pickup football group, from "who's playing?" to paid match entry.

  • Attendance: players confirm with one tap, and the list fills itself.
  • Balanced teams: teams are generated automatically from each player's record, so games stay even.
  • Stats and leaderboards: results, player stats and recent form, to keep the banter going.
  • Payments: match entry is paid through Stripe, so no more chasing cash.

Safety · risk

Pilot Fatigue

StackJavaScript, Chart.js, Claude Artifacts with a shared database RoleProduct and build (MVP)

A fatigue-risk tool for marine pilots. Before each shift, pilots log their sleep and roster, and a fatigue model predicts how tired they will be across the shift.

  • Pilot view: a fatigue score by hour, with green, orange and red zones and the compliance outcome for each shift.
  • Supervisor dashboard: fleet KPIs, a heatmap of peaks by pilot and day, and the incident reports.
  • Alerts: low-sleep breaches, missing logs and escalation to the supervisor.

Construction ops
