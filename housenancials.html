Housenancials: a household financial plan where code does the maths

Objectives, budget, net worth and a 30-years-to-retirement projection in one app. Claude explains the figures and answers what-if questions, but every number is calculated in code.

By Nicolás Martelli · 4 min read

At a glance

What
A web app that connects a household's goals, monthly budget, net worth and retirement plan
My role
Product, design and build
Stack
React, Vite, Tailwind, Supabase (auth, data, Row Level Security, realtime), Vercel serverless functions, Claude API
Status
Live, with a guest mode that runs on example data

1. One plan instead of five spreadsheets

Most budgeting tools stop at tracking spending. Housenancials links the pieces of a household plan, so a change in one place shows up everywhere else: raise the rent and the savings rate, the goal timelines and the retirement projection all move with it.

2. What it does

  • Objectives: goals grouped by horizon (within a year, one to three years, five years or more), with what has been saved so far against each group.
  • Household budget: income and spending lines, monthly or annual, with a bar that shows where the money goes and a warning when the plan spends more than comes in.
  • Net worth: assets and liabilities with expected growth rates, an allocation chart, and a monthly snapshot to build a trend over time.
  • Investing: a projection to retirement from age, contributions, return and inflation, next to the FIRE number (25 times annual expenses).
  • Statement import: load a CommBank CSV export and the app sorts the transactions into budget lines. The file is parsed in the browser and never uploaded.

3. How the AI is used

The rule for the whole app: code does the maths, the AI explains it. A language model that does arithmetic on someone's savings will eventually get a number wrong, so it never does.

  • AI Insights: savings rate, goal timelines, emergency-fund coverage and the FIRE age are computed in code. A serverless function sends those figures to Claude, which returns plain-English observations in a fixed JSON format that the card renders. Results are cached and only refreshed on request.
  • Ask Housenancials: a chat panel for questions like "what if we put an extra $500 a month into investing?". Claude can call two tools: one simulates a change on a copy of the plan and returns the before-and-after figures; the other proposes a change as a card with Apply and Cancel. The server never writes to the plan; only the user's click does.
  • Cost: the chat runs on a small, fast model with prompt caching, which measured at roughly a tenth of a cent per question.

4. Security and trust

  • Data isolation: every household's data is protected by Supabase Row Level Security, so the database itself decides who can read what.
  • No exposed keys: the Claude API key lives only in the serverless functions and never reaches the browser.
  • A safe demo: guests sign in anonymously and work on a separate demo table with example data, locked away from real accounts.
  • Tested maths: automated tests cover the plan calculations the AI features rely on.

5. Try it

Open the live app and choose "Continue as guest" to explore the example household. Changes are shared with other guests, and "Reset demo data" restores the original figures.
